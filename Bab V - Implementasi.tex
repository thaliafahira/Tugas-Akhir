\chapter{IMPLEMENTASI}
\label{chap:implementasi}

Bab ini membahas proses implementasi antarmuka \textit{front-end} aplikasi \textit{tracker} ITB Ultra-Marathon berdasarkan rancangan yang telah disusun pada Bab IV. Implementasi mencakup dua platform, yaitu aplikasi \textit{mobile} untuk kebutuhan pelacakan peserta di lapangan dan aplikasi web untuk kebutuhan pemantauan, administrasi, serta akses publik. Seluruh kode dibangun di atas ekosistem JavaScript menggunakan TypeScript sebagai bahasa pemrograman utama.

\subsection{Implementasi \textit{Front-End} Aplikasi Web}
\label{sec:impl-web}
% ==========================================

Aplikasi web dibangun menggunakan \textit{framework} React 19 dengan \textit{build tool} Vite 8. Sistem navigasi menggunakan TanStack Router yang memungkinkan implementasi autentikasi berbasis peran (\textit{role-based routing}) langsung pada level \textit{router loader}. Antarmuka dibangun dengan pendekatan \textit{utility-first CSS} menggunakan Tailwind CSS 4, sedangkan komponen interaktif menggunakan \texttt{radix-ui} untuk memastikan standar aksesibilitas (\textit{a11y}). Untuk peta interaktif, digunakan \texttt{react-leaflet} dan \texttt{leaflet} murni karena performanya yang ringan dalam me-\textit{render} banyak titik vektor secara bersamaan.

Struktur direktori proyek aplikasi web diorganisasikan berdasarkan tanggung jawab fungsional (\textit{feature-based structure}) sebagaimana ditunjukkan pada Listing \ref{lst:struktur-web}.

\subsection{Implementasi \textit{Front-End} Aplikasi \textit{Mobile}}
\label{sec:impl-mobile}
% ==========================================

Aplikasi \textit{mobile} dibangun menggunakan \textit{framework} React Native dengan platform Expo SDK 54. Arsitektur navigasi menggunakan Expo Router yang berbasis sistem berkas (\textit{file-based routing}). Untuk kebutuhan peta interaktif, implementasi menggunakan pendekatan hibrida yaitu \texttt{react-native-webview} yang menginjeksi halaman Leaflet HTML secara internal. Pendekatan ini dipilih karena \textit{library} peta murni di React Native sering kali tidak mendukung kustomisasi animasi \textit{marker} tingkat lanjut yang dibutuhkan aplikasi. \textit{State} aplikasi dikelola oleh \texttt{zustand} dan data sesi disimpan secara persisten menggunakan \texttt{@react-native-async-storage/async-storage}.

Struktur direktori proyek aplikasi \textit{mobile} dapat dilihat pada Listing \ref{lst:struktur-mobile}.
